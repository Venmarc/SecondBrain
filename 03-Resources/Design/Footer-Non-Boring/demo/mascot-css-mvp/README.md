# Footer mascot MVP (CSS dual-eye)

**Open:** double-click `index.html`, or:

```bash
xdg-open /home/redmane/Documents/SecondBrain/03-Resources/Design/Footer-Non-Boring/demo/mascot-css-mvp/index.html
```

Or from this folder: `python3 -m http.server 8765` then visit `http://127.0.0.1:8765/`.

**Try:** move the cursor; eyes track. Hover footer links (mascot is `pointer-events: none`). With OS “reduce motion”, eyes stay parked and idle anim off.

**Stack:** one HTML file, inline SVG, no build, no Rive. E6320-friendly.
