## Source limits

- The AI Hero website is a first-party source for Matt's own workflow and skill descriptions.
- The workflow is opinionated. It is not proof that every route fits this machine.
- The public API discovery document described protected resource lookup routes, but unauthenticated resource requests returned `401`. No private content was used.
- AI Hero's research skill recommends a background agent. Our machine constitution requires explicit approval before subagent delegation. The local route must resolve that conflict.
- This pass used the site's Markdown, discovery, sitemap, and search surfaces through WebFetch. It did not use Firecrawl. The previous X exploration used the dedicated browser, Defuddle, and a bounded extraction script; it did not use Firecrawl either.
